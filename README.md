عدّاد 1.05 | Addad 1.05

برنامج لويندوز لحساب الجولة الحالية والمجموع الكلي أثناء استخدام التطبيقات الأخرى.

- اختيار زر للزيادة وزر لبدء جولة جديدة.
- إضافة الأعداد بالكتابة وإعادة تعيين الجولة أو المجموع.
- حفظ سجل الجولات والرجوع إليه من داخل التطبيق.
- واجهة عربية وإنجليزية ومظهر نهاري أو ليلي أو حسب الجهاز.
- وضع مصغّر عائم وإيقاف الاختصارات بالماوس.
- تحديث النسخة المثبّتة مع الاحتفاظ بالأعداد والإعدادات والسجل.
